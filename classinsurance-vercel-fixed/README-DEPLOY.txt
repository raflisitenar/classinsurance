CLASSINSURANCE - VERCEL DEPLOY

IMPORTANT:
Deploy the CONTENTS of this folder as the project root, not only index.html.
The deployed root must contain:
index.html
ads.txt
robots.txt
sitemap.xml
vercel.json

AdSense ads.txt URL after deployment:
https://classinsurance.vercel.app/ads.txt

Expected response:
google.com, pub-5129712797856897, DIRECT, f08c47fec0942fa0

If using GitHub + Vercel:
1. Put all files in the repository root.
2. In Vercel, set Framework Preset to Other (or leave auto-detected for static site).
3. Root Directory should be ./ (repository root).
4. Deploy/redeploy.

If using Vercel CLI:
Run `vercel --prod` from inside this folder.
